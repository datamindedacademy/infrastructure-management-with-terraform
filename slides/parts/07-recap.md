# What have we <span class="dm-accent">learned</span>?

<DmColumns class="mt-4">
<DmColumn header="Why IaC" tone="navy">

Infrastructure-as-code allows you to automate and scale your infrastructure deployment, collaborate on infrastructure, and create new abstractions from infra building blocks

</DmColumn>
<DmColumn header="Main Terraform concepts" tone="navy" divider>

- Provider plugins provide resources and data sources
- Terraform state contains the one-to-one mapping of your resources in code to infrastructure in the cloud
- Modules group resources and data sources to create new abstractions
- HCL syntax: types, conditional, iteration

</DmColumn>
<DmColumn header="Development practices" tone="navy" divider>

- Small vs. large state files
- Workspaces for experiments
- Passing information between state via data sources
- Manual state manipulation

</DmColumn>
</DmColumns>
